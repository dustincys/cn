> 这个现实世界太混乱、太复杂。

诸多因素导致我的待办事务、邮件、日期提醒、事务预约等错综复杂、相互干扰。
而如何快速合理地整合这些纷纷扰扰，怎可能难住一个电脑专业人士！

日程管理的核心逻辑是，碰到尘世间纷纷扰扰，把其扔进日程管理系统。
然后，让系统每天自动生成待办事项的报告。
就好比是一个不吃不喝的秘书，我们遇到问题，直接把问题扔给秘书，然后要求秘书随时汇
报当前需要办哪些事，近期需要办哪些事，远期需要办哪些事。

这个日程管理系统的必要功能是将各种待办事项进行排序， 且能够查看当前要办理哪些事
务，然后查看近期还有哪些事需要办，再然后查看远期还有哪些事务需要办。
这样就实现了对短程、中程、长程任务的全场景、全任务、无死角地覆盖。

先设置默认的中程场景任务排序：
```elisp
(setq org-agenda-todo-ignore-scheduled 'all)
(setq org-agenda-todo-ignore-deadlines 'far)
(setq org-log-done 'time)
(setq org-agenda-start-with-log-mode t)
```

再设置长程任务排序：
```elisp
(setq org-agenda-custom-commands
            '(
              ("f" "Far plans"
               (
                (todo ""
                      (
                       (org-agenda-skip-function (lambda () (my-org/skip-todos-by-repeated t)))
                       (org-agenda-todo-ignore-scheduled 'all)
                       (org-agenda-todo-ignore-deadlines 'near)
                       (org-agenda-prefix-format '((todo . " %i %-12:c %(my-org/get-deadline-time) %s")))
                       (org-agenda-overriding-header "Far plans")))
                ))
              ("n" "No deadline plans"
               (
                (todo ""
                      (
                       (org-agenda-skip-function (lambda () (my-org/skip-todos-by-repeated t)))
                       (org-agenda-todo-ignore-with-date t)
                       (org-agenda-overriding-header "No deadline plans")))
                ))
              ("d" "Weekly review"
               (
                (agenda ""
                        (
                         (org-agenda-overriding-header "Completed tasks")
                         (org-agenda-span 'week)
                         (org-agenda-start-day "-6d")
                         (org-agenda-end-day "tomorrow")
                         (org-agenda-skip-function '(org-agenda-skip-entry-if 'nottodo 'done))
                         ))
                ))
              ("rf" "Far repeated plans"
               (
                (todo ""
                      (
                       (org-agenda-todo-ignore-deadlines 'near)
                       (org-agenda-skip-function (lambda () (my-org/skip-todos-by-repeated nil)))
                       (org-agenda-prefix-format '((todo . " %i %-12:c %(my-org/get-deadline-time) %s")))
                       (org-agenda-overriding-header "Far repeated plans")))
                ))
              ("rt" "Near repeated plans"
               (
                (todo ""
                      (
                       (org-agenda-todo-ignore-deadlines 'far)
                       (org-agenda-skip-function (lambda () (my-org/skip-todos-by-repeated nil)))
                       (org-agenda-prefix-format '((todo . " %i %-12:c %(my-org/get-deadline-time) %s")))
                       (org-agenda-overriding-header "Near repeated plans")))
                ))
              ("cp" "Passed scheduled plans"
               (
                (todo ""
                      (
                       (org-agenda-todo-ignore-scheduled 'future)
                       (org-agenda-skip-function (lambda () (my-org/skip-todos-by-scheduled nil)))
                       (org-agenda-prefix-format '((todo . " %i %-12:c %(my-org/get-scheduled-time) %s")))
                       (org-agenda-overriding-header "Passed scheduled plans")))
                ))
              ("cf" "Future scheduled plans"
               (
                (todo ""
                      (
                       (org-agenda-todo-ignore-scheduled 'past)
                       (org-agenda-skip-timestamp-if-done t)
                       (org-agenda-skip-function (lambda () (my-org/skip-todos-by-scheduled nil)))
                       (org-agenda-prefix-format '((todo . " %i %-12:c %(my-org/get-scheduled-time) %s")))
                       (org-agenda-overriding-header "Future scheduled plans")))
                ))
              ))
```

设置重复待办事项、以及事项是否在计划中的双向过滤器：
```elisp
(defun my-org/skip-todos-by-repeated (skip-repeated)
  "Skip TODO items by the LAST_REPEAT property."
  (let ((has-repeated (org-entry-get nil "LAST_REPEAT")))
    (if (eq (eq nil skip-repeated) (eq nil has-repeated))
        (progn
          (outline-next-heading)
          (if (eobp)  ; End of buffer check
              (point-max)  ; Move to the end of the buffer
            (point))))))

(defun my-org/skip-todos-by-scheduled (skip-scheduled)
  "Skip TODO items by scheduled."
  (let ((has-scheduled (org-get-scheduled-time (point))))
    (if (eq (eq nil skip-scheduled) (eq nil has-scheduled))
        (progn
          (outline-next-heading)
          (if (eobp)  ; End of buffer check
              (point-max)  ; Move to the end of the buffer
            (point)))  ; Continue to the next heading
      nil)))
```

给待办事项添加时间标签：

```elisp
(setq org-agenda-prefix-format '((todo . " %i %-12:c %(my-org/get-deadline-time) %s")))
(add-hook 'org-agenda-finalize-hook #'my-org/color-dates-in-agenda)
```

按照时间距离当前时间的远近，给时间标签添加渐变色背景：

```elisp
(defun my-org/scheduled-time-face (time-diff)
  "Return the appropriate face based on TIME-DIFF in seconds."
  (cond
    ((> time-diff 720) '(:foreground "black" :background "#00FF00"))
    ((> time-diff 360) '(:foreground "black" :background "#66FF66"))
    ((> time-diff 180) '(:foreground "black" :background "#99FF99"))
    ((> time-diff 90) '(:foreground "black" :background "#CCFFCC"))
    ((> time-diff 60) '(:foreground "black" :background "#FFCCCC"))
    ((> time-diff 30) '(:foreground "black" :background "#FF99FF"))
    ((> time-diff 15) '(:foreground "black" :background "#FF66FF"))
    ((> time-diff 7) '(:foreground "black" :background "#FF33FF"))
    ((> time-diff 0) '(:foreground "black" :background "#FF00FF"))
    (t '(:foreground "black" :background "red"))
    ))


(defun my-org/get-scheduled-time ()
  "Return the scheduled time of the current Org entry as a string with a face."
  (let ((scheduled (org-get-scheduled-time (point)))
        (now (current-time)))
    (if scheduled
        (format-time-string "[%Y-%m-%d]" scheduled)
      "")))


(defun my-org/get-deadline-time ()
  "Return the scheduled time of the current Org entry as a string with a face."
  (let ((dealined (org-get-deadline-time (point)))
        (now (current-time)))
    (if dealined
        (format-time-string "[%Y-%m-%d]" dealined)
      "")))

(defun my-org/color-dates-in-agenda ()
  "Color scheduled dates based on their proximity to now in the agenda buffer."
  (let ((inhibit-read-only t))
    (save-excursion
      (goto-char (point-min))
      (let ((pattern "\\[\\([0-9]\\{4\\}-[0-9]\\{2\\}-[0-9]\\{2\\}\\)\\]"))
        (while (re-search-forward pattern nil t)
          (let* ((date-str (match-string 1))
                  (date (date-to-time date-str))
                  (time-diff (- (time-to-days date) (time-to-days (current-time))))
                  (face (my-org/scheduled-time-face time-diff)))
            (let ((line-start (line-beginning-position))
                  (line-end (line-end-position)))
              (save-excursion
                (goto-char line-start)
                (if (re-search-forward pattern line-end t)
                    (put-text-property (match-beginning 0) (match-end 0) 'face face)
                  nil))
              )))))))
```

然后再配合`org-super-agenda`，构成了完美的日期自动管理系统。
再然后就可以快意恩仇、歇斯底里、大杀四方！！！

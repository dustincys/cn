> All my best memories come back clearly to me. It is yesterday once more.  
> 那些珍藏的时光，如潮水般涌回心间，仿佛昨日在眼前轻轻铺展。

归国后，我渐渐倾心于Debian发行版的Linux，它如一位沉稳的老友，以无比的可靠与宁静
陪伴左右：

* ‌严苛的考验‌：稳定版历经时光打磨，软件包皆经过漫长验证，每两至三年方更新一次，恰
  似为服务器与重任之地筑起坚固堡垒。
* ‌自由的节奏‌：透过APT，我可随心择选更新，甚至守护特定软件免于变迁，避开意外波澜，
  让一切如诗般从容。

在将Linux植入Dell台式机前，我细细探看硬件与支持，发现无线网卡的驱动自Debian13内
核始得拥抱。安装毕，我迫不及待想重拾[fvwm2](https://github.com/dustincys/fvwm)与
[hifvwm](https://github.com/dustincys/hifvwm)的旧梦。

fvwm2的设计哲学，深得我心，宛如一首未完成的诗篇。2017至2018年间，我在[原
作](https://github.com/fvwmorg/fvwm)的基底上，添上了最小化缩略图的灵韵、最小化图
标的透明幻影，以及返回上桌面页面的轻巧函数，让透明效果浑然一体，如梦境般连贯。

我下载源码，欲在本地编织，却见编译中错误丛生——Debian13的依赖库已不再支持往昔的痕
迹。转而一试，apt install fvwm 竟能从Debian源中轻松获取，原来这包裹已被社区巧妙
修饰，依赖库悄然更迭。

当用 apt-get source 命令采撷源码时，它携来完整的包裹，内含上游代码与Debian的补丁
缀饰。社区在构建二进制包时，依循 debian/rules 的指引，将这些补丁轻轻缝合，融入
Debian独有的匠心。这机制让定制如流水般自然，既保留上游的纯净，又织入自身的华彩。

如何将我往昔对fvwm2的个性化雕琢，直接烙入Debian的源码，让“昨日重现”？

1. 步入我的fvwm2文件夹，将2017到2018年的代码修改细细收拢，打包成补丁的画卷：
```shell
git log --author="dustin" --pretty=format:"%H" | xargs -I {} git show {} --pretty=format: --patch > dustin_total.diff
```

2. 踏入Debian的fvwm2源码殿堂，将这补丁轻柔嵌入：
```shell
 patch -p1 < ~/github/fvwm/dustin_total.diff
```

3. 重新构筑Debian的fvwm软件包，如匠人打磨珍品：
```shell
 debuild -us -uc -b
```

4. 最终，将这心血之作安放妥帖：
```shell
dpkg -i fvwm*.deb
```
